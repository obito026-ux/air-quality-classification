# Air Quality Classification

## Project Description

This project predicts air quality using machine learning.

The project uses air pollution parameters such as:

- PM2.5
- PM10
- NO2
- SO2
- CO
- O3

A Random Forest Classifier is used to classify air quality.

## Air Quality Categories

| Value | Category |
|---|---|
| 1 | Hazardous |
| 2 | Poor |
| 3 | Moderate |
| 4 | Good |
| 5 | Excellent |
